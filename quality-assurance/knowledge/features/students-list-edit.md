# Students — list, search, edit and remove

**Source of truth:** issue #3 "View and search the student list" (AC1–AC3) and issue #4 "Edit or
remove a student" (AC4–AC6) · delivered in PR #16 · last tested 2026-10-21 (cycle 1: 66 cases,
61 pass, 1 new Medium bug, 1 Low a11y, 2 known-bug carry-overs; verdict PASS).

## Acceptance criteria

1. The list shows each student's name, roll number and class. (issue #3)
2. Typing in the search box filters the list by name. (issue #3)
3. "No students found" shows when nothing matches. (issue #3)
4. Open a student and edit their details with the same validation as when adding. (issue #4)
5. Removing a student asks for confirmation first. (issue #4)
6. After removal the student no longer appears in the list. (issue #4)
7. Inferred (PR body): roll numbers are DB-assigned, unique, never change on edit, not reused.
8. Inferred (PR body): search is case-insensitive, matches `"<first> <last>"`, `%`/`_`/`\` literal.

## Verified safe (2026-10-21)

- Migration: `roll_number integer NOT NULL GENERATED BY DEFAULT AS IDENTITY`, unique index, no column
  default; explicit duplicate insert → unique violation; deleted numbers are not reused.
- PUT keeps `id`, `roll_number`, `created_at_utc`; trims names/email; blank email → NULL; validation
  identical to POST (same keys and messages); invalid body on unknown id → 400 (validation first).
- Search: parameterised ILIKE, escaping of `\` `%` `_` correct; 600-char term fine; whitespace-only
  = unfiltered; term trimmed before the request; ~10 keystrokes → 1 request.
- Remove: `DELETE` 204/404, 404 treated as removed (two-tab case shows success toast); double-click
  on confirm → one DELETE; Escape/Cancel close without a request; dialog has role `dialog`,
  `aria-labelledby` = "Remove student?", focus moves inside.
- Double-click Save on edit → one PUT. Browser Back after save shows the saved values.
- `/students/not-a-guid/edit` → "Page not found" (route constraint).

## Observations (not bugs)

- Search matches first-then-last order only (`"Searchable Qa"` → nothing); `'` and `’` distinct.
- Search term is not in the URL; F5 clears it.
- Sidebar "Students" lacks `aria-current` on `/students/new` and `/students/{id}/edit` (pre-existing).
